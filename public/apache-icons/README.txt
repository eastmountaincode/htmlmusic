Public-domain Apache autoindex icons

These files are exact copies from the Apache HTTP Server icon set:
https://github.com/apache/httpd/tree/trunk/docs/icons

Apache's README states that the icons were originally made for Mosaic for X,
were included with NCSA httpd and Apache, and are in the public domain. The
originals were made by Kevin Hughes; Andy Polyakov tuned the colors and added
several images.

Included here:
- back.gif
- blank.gif
- folder.gif
- sound2.gif
- text.gif
